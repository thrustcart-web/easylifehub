# AutoBlog — نظام نشر تلقائي لمدونة بلوجر بمقالات أفلييت لأمازون

**بدون سيرفر · إعداد مركزي · نشر تلقائي · مع تحكم في حدود استهلاك الخدمات**

النظام يكتب مقالات ريفيو ومقارنات وأدلة شراء لمنتجات أمازون، يركّب لينكات الأفلييت بتاجك،
وينشرها على بلوجر في مواعيد ثابتة كل يوم — من غير أي تدخل منك، ومن غير الإيميل السري.

---

## الفكرة في سطر

```
GitHub Actions (يولّد المقالات عند طلب التعبئة التلقائية)
        ↓  يحفظها في content/queue/
Google Apps Script (يتابع الطابور ويُجدول النشر)
        ↓  يستخدم صلاحيات حساب جوجل المتصل
Blogger API v3
```

**ليه التقسيم ده؟**
- **GitHub Actions** بيكتب ويجهّز — عنده مساحة ملفات ومرونة، وبيشتغل حتى لو نمت.
- **Apps Script** بينشر — يتابع مواعيد النشر ويطلب تعبئة الطابور تلقائيًا عند انخفاض المحتوى.
- **Blogger API** يستخدم صلاحيات حساب Google الذي يشغّل Apps Script؛ لذلك يجب أن تظل صلاحيات الحساب والتفويض صالحة.

## سلسلة كتابة المقالات والبحث عن المنتجات

كتابة المقال تمر بالترتيب التالي: **Groq → OpenRouter → Gemini**. إذا فشلت الخدمات الثلاث، يتوقف توليد المقال ولا يُنشر مقال قالب بديل؛ هذه حماية مقصودة حتى لا تدخل مقالات غير مولّدة بالذكاء الاصطناعي إلى الطابور.

البحث عن المنتجات يبدأ بـ **Amazon Creators API**. إذا تعذر البحث أو لم يظهر عنوان يطابق المنتج، يمكن استخدام **SerpApi** كبديل فقط عند وجود مفتاحه وتفعيل متغير GitHub Actions `SERPAPI_SPEND_ENABLED=true` والسماح بالـ fallback في التشغيل. **Apify غير مفعّل في التشغيل التلقائي**.

يوجد **Queue** للمقالات الجاهزة، ويتابع Apps Script عدد المقالات المتاحة ويطلب تعبئته تلقائيًا عند انخفاضه. فشل البحث عن منتج لا يسمح بإنشاء رابط Amazon غير متحقق.

## الحماية من الحظر (ده أهم جزء في المشروع)

بلوجر فيها فلاتر Spam بتقفل الـ API للحسابات اللي بتنشر آلي بكثافة. عشان كده:

- **6 مقالات يومياً كحد أقصى**، بمواعيد نشر 9، 11، 13، 15، 17، 19 بتوقيت القاهرة، مع فاصل لا يقل عن ساعتين بين المقالات.
- **تأخير عشوائي 0–20 دقيقة** داخل كل ساعة نشر — مفيش طابع زمني ثابت.
- **Circuit Breaker**: بعد 3 أخطاء متتالية النظام **بيوقف نفسه 24 ساعة** ويبعتلك إيميل، بدل ما يفضح الحساب.
- **Quality Gate**: بيرفض أي مقال فيه محتوى رقيق، جمل مكررة، أسعار مختلَقة، عبارات AI مفضوحة
  (زي "in today's fast-paced world")، أو link stuffing.
- **تنويع حقيقي**: 3 قوالب (ريفيو / مقارنة / قائمة) بنظام Deficit Scheduling يضمن التوازن،
  و8 صيغ عناوين مختلفة، و6 أصوات كتابية.

## التشغيل محلياً (للتجربة قبل الإعداد)

```bash
# من غير أي مفاتيح — يستخدم المحرك الأوفلاين
python3 main.py --count 5 --mode template

# معاينة المدونة في المتصفح
python3 preview_server.py

# الاختبارات (مجموعة اختبارات offline، من غير طلبات API)
python3 tests/test_pipeline.py

# الحالة
python3 main.py --stats
```

## الملفات

```
config.json                     ← كل الإعدادات (عدّل هنا بس)
main.py                         ← نقطة الدخول
preview_server.py               ← معاينة محلية للمقالات
scripts/
  providers.py                  ← سلاسل الـ AI المجانية مع fallback
  ai_writer.py                  ← البرومبتات + التحقق + تنظيف المخرجات
  template_engine.py            ← المحرك الأوفلاين (شبكة الأمان)
  topic_planner.py              ← اختيار الموضوع التالي + صيغ العناوين
  keywords.py                   ← تحليل الكلمات المفتاحية لعناصر منتج حقيقية
  render.py                     ← المقال → HTML جاهز لبلوجر + Schema.org
  affiliate.py                  ← اللينكات + الإفصاح + product boxes
  images.py                     ← Unsplash (كاش) أو SVG محلي
  safety.py                     ← Quality Gate + Circuit Breaker + حدود المعدل
  blogger.py                    ← Blogger API v3 بالـ Service Account
  generate.py                   ← تجميع البايبلاين
appsscript/Code.gs              ← المُجدوِل (انسخه في Apps Script مرة واحدة)
.github/workflows/              ← الجدولة اليومية + الاختبارات + keepalive
data/keywords.csv               ← 2561 موضوع جاهز (سنتين محتوى)
data/products.csv               ← منتجاتك بـ ASIN (اختياري)
content/seed/                   ← 6 مقالات مكتوبة بإيد، تُنشر أولاً
content/queue/                  ← الطابور اللي بيقرأه الناشر
docs/SETUP_AR.md                ← دليل الإعداد خطوة بخطوة بالعربي
```
