# تصوّر الأوتوميشن الكامل — من المنتج إلى المنشور من غير تدخل

الملف ده بيشرح **إزاي** النظام شغال من جوه. لو عايز تعدّل حاجة أو تفهم سبب قرار معيّن، ابدأ من هنا.

## 2) رحلة مقال واحد (مثال حقيقي)

```
data/keywords.csv:
  keyword = "best robot vacuum for pet owners"
  niche   = "home cleaning"
  feature = "suction power"
  audience= "pet owners"
        ↓
keywords.py يحللها:
  base     = "robot vacuum"        ← المنتج الحقيقي
  head     = "vacuum"              ← العائلة
  audience = "pet owners"
  budget   = ""
  intent   = "bestof"
        ↓
topic_planner.py يجمّعها:
  عائلة "vacuum" فيها: robot vacuum, stick vacuum, handheld vacuum
  → ينفع تعمل مقارنة ✔  → ينفع تعمل قائمة ✔
  Deficit scheduling يقول: المقارنة ناقصة → اختار "comparison"
        ↓
  title = "Robot Vacuum or Stick Vacuum? The Honest Comparison"
  slug  = "comparison-robot-vacuum-vs-stick-vacuum-8f3a2c"
  items = [
    {display_name: "Robot Vacuum",  search_term: "best robot vacuum for pet owners"},
    {display_name: "Stick Vacuum",  search_term: "cordless stick vacuum for hardwood"}
  ]
        ↓
ai_writer.py يبني البرومبت:
  · الصوت: "مشتري صريح تعبان من كلام التسويق"
  · الإيقاع: "جمل قصيرة غالباً، جملة واحدة طويلة في كل قسم"
  · العنوان: **مفروض** — مش مسموح للموديل يغيّره
  · ممنوع: أسعار، تقييمات، "اختبرناه 40 ساعة"، 20 عبارة محظورة
  · مطلوب: سلبيات حقيقية، 1500 كلمة، JSON فقط
        ↓
Groq يرد → extract_json يستخرج الـ JSON → normalise ينضّفه
        ↓
validate():  ✅ 1740 كلمة · 6 أقسام · 5 سلبيات · 5 أسئلة · مفيش أسعار
        ↓
render.py:
  · <style> مدمج (بلوجر بيشيل الـ CSS الخارجي)
  · صورة غلاف (Unsplash من الكاش، أو SVG مولّد)
  · إفصاح الأفلييت في الأول
  · JSON-LD: Article + Product + Review + FAQPage + ItemList
  · جدول المحتويات
  · جدول المقارنة من comparison_rows
  · pros/cons في عمودين
  · FAQ في <details> (بتظهر كـ Rich Results في جوجل)
  · 3 أزرار CTA + product boxes
  · أول ذكر لكل منتج يبقى لينك أفلييت (من غير حشو)
        ↓
quality_gate(): ✅ مفيش جمل مكررة · مفيش حشو لينكات · الإفصاح موجود
        ↓
content/queue/comparison-robot-vacuum-vs-stick-vacuum-8f3a2c.{html,json,md}
        ↓
git push  →  بعد كام ساعة  →  Apps Script ينشره  →  🎉
```

## 3) الجدول الزمني في اليوم العادي

| الوقت (UTC) | الوقت (القاهرة) | إيه اللي بيحصل | مين |
|---|---|---|---|
| 03:00 | 05:00 | توليد 3 مقالات + commit | GitHub Actions |
| 04:30 كل 5 أيام | 06:30 | keepalive commit (منع تعطيل الجدولة) | GitHub Actions |
| 07:00 | 09:00 | Trigger → مش ساعة نشر → خروج فوري | Apps Script |
| **07:00** | **09:00** | ✅ Trigger → ساعة نشر → نوم عشوائي 0-20 د → **نشر مقال** | Apps Script |
| 08:00–10:00 | 10:00–12:00 | Triggers → خروج فوري | Apps Script |
| **11:00** | **13:00** | ✅ **نشر المقال الثاني** | Apps Script |
| **16:00** | **18:00** | ✅ **نشر المقال الثالث** | Apps Script |
| الأحد 18:00 | 20:00 | ملخص أسبوعي بالإيميل (اختياري) | Apps Script |

> **ليه Trigger كل ساعة بدل cron على الساعة 9 بالظبط؟**
> لأن Apps Script بيديك دقة بالثانية من غير drift، والتحقق من الساعة بيدّيك تحكم كامل
> في المواعيد من Script Properties من غير ما تلمس الكود. والساعات اللي مش بتاعتنا
> بتخرج في أقل من ثانية (استدعاء واحد مجاني).

## 4) إزاي النظام **مستحيل** يقف

ده أهم تصميم في المشروع كله. كل نقطة فشل عندها بديل:

| لو حصل... | النظام بيعمل إيه | النتيجة |
|---|---|---|
| Groq خلص الـ quota | يجرب Mistral | مقال عادي |
| كل مفاتيح الـ AI خلصت | **template_engine أوفلاين** | مقال كامل 1600 كلمة ✅ |
| مفيش نت خالص في الـ runner | template_engine | مقال كامل ✅ |
| Unsplash رفض أو مفيش مفتاح | **SVG مولّد محلياً** | صورة غلاف أنيقة ✅ |
| الموديل رجّع JSON بايظ | extract_json يستخرج أول object متوازن | مقال عادي |
| الموديل كتب سعر مختلَق | validate يرفض → يعيد المحاولة مع تصحيح | مقال نضيف ✅ |
| المقال طلع رقيق بعد كل ده | template_engine | مقال كامل ✅ |
| Blogger API رجّع خطأ | FAIL_COUNT += 1، يوقف اليوم | حماية الحساب |
| 3 أخطاء ورا بعض | **Circuit Breaker** يقفل 24 ساعة + إيميل | مفيش حظر ✅ |
| GitHub عطّل الـ workflows | keepalive commit كل 5 أيام | الجدولة تفضل شغالة ✅ |
| الطابور فاضي | index.json فاضي → Apps Script يخرج + إيميل | مفيش مقال بايظ |
| state.json باظ | backup + إعادة بناء | مفيش فقدان |
| الريبو كبر أوي | prune_queue يخلي آخر 60 مقال بس | الريبو يفضل صغير ✅ |

**الخلاصة:** أسوأ سيناريو ممكن = مقال مكتوب بالمحرك الأوفلاين بصورة SVG.
يعني **في كل الحالات فيه مقال بيتنشر**.

## 5) حدود الأمان المقفولة في الكود

القيم دي **مشفّرة في الكود**، مش بس في الإعدادات، عشان حتى لو عدّلت الإعدادات
بشكل يضرّك النظام يحميك:

```python
# safety.py
max_posts_per_day_hard_cap = 6     # حتى لو حطيت 25 في config
min_seconds_between_posts  = 7200  # ساعتين بين أي مقالين
max_consecutive_failures   = 3     # بعدها Circuit Breaker
cooldown_hours             = 24    # مدة الإيقاف
min_words                  = 1150  # أقل من كده = مرفوض
LINK_SPAM_THRESHOLD        = 25    # أكثر من كده لينك = مرفوض
REPEATED_SENTENCE_LIMIT    = 3     # جملة اتكررت 4 مرات = مرفوض
BANNED_PHRASES             = 20    # عبارات AI مفضوحة = مرفوض
```

وفي Apps Script:
```javascript
MAX_PER_DAY   = 3          // Script Property
MIN_GAP_HOURS = 2          // Script Property
JITTER_MAX    = 1200       // 0–20 دقيقة عشوائي
```

## 6) إيه اللي بيخلي المحتوى **مش** شكله آلي

ده اللي بيفرق بين مدونة بتكسب ومدونة بتتقفل:

| التقنية | إزاي بتتنفذ |
|---|---|
| **تنويع القوالب** | Deficit Scheduling يضمن 46/30/24% توزيع حقيقي |
| **تنويع العناوين** | 8 صيغ ريفيو + 6 صيغ قائمة + 4 صيغ مقارنة، مع ذاكرة بتمنع التكرار |
| **تنويع الصوت** | 6 شخصيات كتابية × 5 أنماط إيقاع = 30 تركيبة |
| **تنويع النيتش** | مفيش نيتش بيتكرر في 3 مقالات ورا بعض |
| **تنويع الموضوع** | cooldown 120 يوم على كل موضوع قبل ما يتكرر |
| **مفيش جمل مكررة** | detector بيقعد يقارن كل الجمل في المقال |
| **سلبيات حقيقية** | مقال من غير `cons` مرفوض تلقائياً |
| **مفيش أرقام مختلَقة** | أي `$` أو `4.5/5` أو "اختبرناه" = رفض |
| **طابع زمني بشري** | نشر في أوقات مختلفة + تأخير عشوائي |
| **طول طبيعي** | 1500–2200 كلمة، مش 500 ولا 4000 |

## 7) إحصائيات النظام الحالية

```
data/keywords.csv    →  2561 موضوع · 18 نيتش · 197 منتج · 6 عائلات قابلة للمقارنة
data/products.csv    →  3 أمثلة (إنت تملاها)
content/seed/        →  6 مقالات مكتوبة بإيد (2100–2450 كلمة)
قوالب المقالات        →  3 (ريفيو · مقارنة · قائمة)
صيغ العناوين          →  18
مصادر AI             →  4 + محرك أوفلاين
حدود الأمان           →  12 حد مقفول في الكود
اختبارات              →  31 اختبار آلي (من غير نت) · كلها خضرا
```

**عمر المحتوى:** محاكاة كاملة لـ **700 يوم** أنتجت **2100 مقال فريد** بصفر تكرار وصفر أيام فاضية.
يعني **~سنتين** نشر متواصل من غير ما تلمس حاجة، وبعدها النظام بيعيد تدوير المواضيع
بصيغ عناوين وزوايا مختلفة (سلوك طبيعي في مدونات الأفلييت).

> **ملاحظة أداء:** `data/*.csv` بتتحلل مرة واحدة في التشغيل (memoised).
> التحليل الكامل لـ 2561 صَف بيخد أقل من ثانية.

## 8) التوسعات المستقبلية (اختياري تماماً)

لو حبيت تطوّر بعدين، الترتيب ده حسب العائد:

1. **`data/products.csv` بمنتجات حقيقية** — أعلى تحويل بكثير من لينكات البحث.
2. **مراجعة بشرية خفيفة** — من `preview_server.py`، 5 دقايق لكل 10 مقالات.
3. **Blogger custom domain** — دومين بـ 10 دولار/سنة يرفع الثقة جداً.
4. **Search Console** — أضف مدونتك وشوف إيه اللي بيترتب فعلاً، وزوّد منه.
5. **نيشات جديدة** — ضيف صفوف في `keywords.csv` والنظام هيتعامل معاها فوراً.
6. **مقالات عربية** — `config.json` → `content.language: "ar"` (البرومبت بيدعمه).
