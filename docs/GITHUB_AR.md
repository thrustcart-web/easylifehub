## الحالة أ: رفعت ملف الـ ZIP نفسه

المشكلة: GitHub مش بيفك الضغط. لازم **إنت** تفكه على جهازك وترفع **اللي جواه**.

### الحل (الأسهل: امسح وابدأ من جديد)

1. في صفحة الريبو، اضغط على اسم الملف **`AutoBlog-Project.zip`**
2. فوق على اليمين هتلاقي **3 نقط** `···` → اضغطها
3. اختار **Delete file**
4. انزل تحت → **Commit changes** (زرار أخضر)

### دلوقتي ارفع صح

5. على جهازك: **كليك يمين** على `AutoBlog-Project.zip` → **Extract All...** → **Extract**
   - هيتعمل مجلد جديد. **ادخل جواه**
   - جوه المجلد ده لازم تشوف: `scripts` و `data` و `docs` و `content` و `.github` و `config.json` و `main.py`

6. ⚠️ **قبل ما تكمل: طلّع الملفات المخفية** عشان تشوف `.github`
   - **ويندوز 11:** افتح أي مجلد → فوق اضغط **View** → **Show** → علّم على **Hidden items**
   - **ويندوز 10:** افتح أي مجلد → تاب **View** → في مجموعة "Show/hide" علّم على ☑ **Hidden items**
   - **ماك:** في Finder اضغط **Cmd + Shift + .** (نقطة)

7. ارجع لـ GitHub → في صفحة الريبو اضغط **Add file** (فوق، جنب الـ Go to file)
   → **Upload files**

8. **اسحب كل اللي جوه المجلد المفكوك** (مش المجلد نفسه!) إلى المنطقة المتقطعة
   - طريقة تانية: اضغط **choose your files** واختارهم كلهم
   - ⚠️ **متسحبش المجلد نفسه** — لازم تسحب **محتوياته**

9. استنى لحد ما كل الأسماء تظهر في القائمة (39 عنصر)

10. انزل تحت لـ **Commit changes**:
    - **Commit message:** اكتب `AutoBlog initial upload`
    - علّم على ⦿ **Commit directly to the `main` branch**
    - اضغط الزرار الأخضر **Commit changes**

11. استنى 10–30 ثانية → الصفحة هتعمل refresh

**✅ لازم تشوف:** قائمة فيها `scripts` و `data` و `docs` و `.github` و `config.json`

## الحالة ب: كل الملفات جوه مجلد واحد

يعني شايف مثلاً:
```
📁 affiliate-blog     ← كل حاجة جوه هنا
```

وده **مش هيشتغل** لأن GitHub Actions بيدور على `.github/workflows/` في **جذر الريبو**،
مش جوه مجلد.

### الحل

**الطريقة الأسهل: ارفع تاني في الجذر**

1. على جهازك ادخل **جوه** المجلد المفكوك
2. اختار **كل اللي جواه** (Ctrl+A)
3. GitHub → **Add file** → **Upload files** → اسحبهم
4. **Commit directly to the `main` branch** → **Commit changes**
5. دلوقتي هيبقى عندك نسختين: واحدة في الجذر (صح) وواحدة جوه المجلد (غلط)
6. امسح المجلد القديم:
   - اضغط على اسم المجلد القديم (مثلاً `affiliate-blog`)
   - ادخل جواه → اضغط على أول ملف → **3 نقط** `···` → **Delete file**
   - كرّر لكل ملف... **ده ممل** 👇

**الطريقة الأسرع بكتير: امسح الريبو واعمله من جديد**

1. GitHub → تاب **Settings** (آخر تاب على اليمين)
2. انزل لآخر الصفحة خالص لـ **Danger Zone** (منطقة حمرا)
3. **Delete this repository** → هيطلب منك تكتب اسم الريبو للتأكيد
4. اكتب الاسم بالظبط (مثلاً `username/autoblog`) → **I delete this repository**
5. اعمل ريبو جديد من **https://github.com/new** وارفع صح من الأول (الحالة أ، خطوة 5)

> 💡 **الخسارة 3 دقايق بس.** أسهل بكتير من مسح 39 ملف واحد واحد.

## الحالة ج: مجلد `.github` مرفوعش

دي أشهر مشكلة لأن المجلد **مخفي** على ويندوز وماك.

### تأكد الأول

1. في صفحة الريبو، بص على القائمة — فيه `.github`؟
   - **أيوه** → تمام، skip القسم ده وروح [للخطوة 3](#الخطوة-3-فعّل-الـ-actions)
   - **لأ** → كمّل تحت

### الحل: اعمل الـ 4 ملفات يدوي (5 دقايق)

هتعمل كل ملف بنفس الطريقة. **4 مرات بس.**

#### الملف الأول

1. في صفحة الريبو اضغط **Add file** → **Create new file**

2. في خانة الاسم (اللي مكتوب فيها `Name your file...`) اكتب **بالظبط**:
   ```
   .github/workflows/tests.yml
   ```
   ⚠️ **أهم حاجة:** أول ما تكتب `.github/` وبعدها `/` هتلاقي GitHub غيّر الشكل —
   بقى فيه breadcrumb فوق. **ده معناه إنه بيعمل المجلدات لوحده.** ✅
   
   ⚠️ ولو رفض يكتب نقطة في الأول: اكتب الاسم في **Notepad** الأول، اعمل Copy،
   والصقه في الخانة.

3. في المساحة الفاضية الكبيرة تحت، الصق محتوى الملف.
   
   المحتوى كله موجود في ملف **`WORKFLOWS-FALLBACK_AR.md`** اللي في المشروع —
   افتحه من جهازك وانسخ منه.

4. انزل تحت → **Commit changes** → **Commit changes** تاني

#### الملف التاني والتالت والرابع

كرر نفس الخطوات بالظبط مع الأسماء دي:

```
.github/workflows/generate-daily.yml
.github/workflows/keepalive.yml
.github/workflows/refill-queue.yml
```

كل المحتوى موجود في `WORKFLOWS-FALLBACK_AR.md` بالترتيب.

**✅ التأكد:** في صفحة الريبو لازم تشوف مجلد `.github` وجواه `workflows` وجواه 4 ملفات.

## الخطوة 3: فعّل الـ Actions

> دي خطوة **إجبارية**. GitHub بيوقف الـ workflows في الريبو الجديد لحد ما توافق.

1. في صفحة الريبو، بص على **شريط التابات اللي فوق**:
   ```
   Code   Issues   Pull requests   Actions   Projects   Wiki   Security   Settings
   ```
   اضغط **Actions**

2. **لو شفت صندوق أزرق/أصفر** فيه كلام عن الـ workflows:
   - فيه زرار اسمه:
     **"I understand my workflows, go ahead and enable them"**
   - اضغطه ✅
   - **خلاص، اتفعّلت.**

3. **لو ملقتش الزرار ده:** يبقى متفعّلة أصلاً. كمّل عادي.

4. **التأكد:** على الشمال هتلاقي قائمة:
   ```
   All workflows
     generate-daily
     keepalive
     refill-queue
     tests
   ```
   لو القائمة دي ظاهرة → ✅ **تمام، الـ 4 workflows موجودة وشغالة**

> ❌ **لو القائمة فاضية أو مكتوب "There aren't any workflows yet"**
> يبقى مجلد `.github` مرفوعش → ارجع [للحالة ج](#الحالة-ج-مجلد-github-مرفوعش)

## الخطوة 4: شغّل توليد المقالات (زرار واحد)

1. لسه في تاب **Actions**
2. على **الشمال**، اضغط على **`generate-daily`**
3. فوق على **اليمين** هتلاقي زرار **`Run workflow`**
   - لو مش ظاهر: اضغط على **`main`** في القائمة المنسدلة (Branch) الأول
4. اضغط **`Run workflow`** → هتفتحلك قايمة صغيرة فيها خانتين:
   ```
   How many articles to generate    [ 3 ]     ← غيّرها لـ 6
   auto | ai | template             [ auto ]  ← سيبها زي ما هي
   ```
5. اضغط الزرار الأخضر **`Run workflow`** (اللي جوه القائمة)

6. استنى **2–4 دقايق**. اعمل **Refresh** للصفحة كل نص دقيقة.

7. **هتشوف إيه:**
   - في الأول: دايرة صفرا 🟡 = شغال
   - بعد شوية: علامة ✅ خضرا = نجح
   - لو ❌ حمرا = فشل → اضغط عليه → اضغط على `generate` → شوف اللوج

8. **لو ظهر خطأ في اللوج فيه كلمة `GROQ_API_KEY` أو `provider`:**
   - **ده مش خطأ حقيقي** — النظام بيقولك "مفيش مفاتيح AI، هستخدم المحرك الأوفلاين"
   - بص في اللوج على سطر: `using offline template engine`
   - ولو في الآخر مكتوب **`DONE | queued=6`** → ✅ **اشتغل تمام**

## الخطوة 6: عدّل `config.json` (من غير ما تحمل حاجة)

1. ارجع لتاب **Code** → اضغط على **`config.json`**
2. فوق على اليمين هتلاقي أيقونة **قلم** ✏️ (Edit this file)
   - لو مش شايفها: اضغط **3 نقط** `···` → **Edit file**
3. الملف هيفتح في محرر. عدّل القيم دي:

```json
"blog": {
  "id": "1234567890123456789",
```
⬅️ حط الـ **Blog ID** بتاعك (من شريط عنوان بلوجر: `blogger.com/blog/posts/1234567890123456789`)

```json
  "url": "https://yourname.blogspot.com",
  "name": "اسم مدونتك"
```

```json
"affiliate": {
  "tag": "mypicks-20",
```
⬅️ حط **تاج الأفلييت** بتاعك

```json
"github": {
  "repo_raw_base": "https://raw.githubusercontent.com/USERNAME/autoblog/main"
}
```
⬅️ غيّر **`USERNAME`** لاسمك على GitHub، و**`autoblog`** لاسم الريبو لو مختلف

4. ⚠️ **مهم جداً:** متغيرش **الفواصل `,`** ولا **علامات التنصيص `"`** ولا **الأقواس `{ }`**
   - لو مسحت فاصلة بالغلط، النظام كله هيقف
   
   **تأكد إنك عدّلت القيم اللي جوه التنصيص بس.**

5. فوق على اليمين: **Commit changes...**
6. اكتب رسالة: `config: my blog` → **Commit changes**

### تأكد إنك مكسرتش حاجة

7. اضغط على مجلد **`.github`** → **`workflows`** → **`tests.yml`**
8. تاب **Actions** → شوف آخر run → ✅ أخضر؟ **تمام، الـ JSON سليم**
   - ❌ أحمر؟ يبقى فيه غلطة في `config.json` → ارجع وعدّل

## الخطوة 7: ضيف مفاتيح الـ AI (Secrets)

1. تاب **Settings** (آخر تاب على اليمين)
2. على **الشمال**، انزل لـ **Secrets and variables** → اضغط **Actions**
3. هتلاقي تبويبين: **Secrets** و **Variables**

### أ) Secrets (اضغط زرار **New repository secret**)

ضيف كل واحد لوحده — **Name** و **Secret** ثم **Add secret**:

| Name | Secret |
|---|---|
| `GROQ_API_KEY` | مفتاح Groq (من console.groq.com → API Keys) |
| `AFFILIATE_TAG` | تاج الأفلييت بتاعك (مثلاً `mypicks-20`) |
| `MISTRAL_API_KEY` | *(اختياري)* |
| `OPENROUTER_API_KEY` | *(اختياري)* |
| `GEMINI_API_KEY` | *(اختياري)* |
| `UNSPLASH_ACCESS_KEY` | *(اختياري — للصور)* |

⚠️ **الأسماء لازم تكون بالحروف الكبيرة بالظبط** زي ما مكتوبة فوق.
⚠️ **متحطش مسافات** قبل أو بعد الاسم.

### ب) Variables (اضغط **New repository variable**)

| Name | Value |
|---|---|
| `DAILY_POSTS` | `3` |

## 🆘 مشاكل شائعة

### "أنا مش لاقي زرار Add file"
الزرار ده بيظهر **بس لما الريبو فيه ملفات على الأقل**. لو الريبو فاضي تماماً،
هتشوف صفحة "Quick setup" → روح [للحالة د](#الحالة-د-الريبو-لسه-فاضي)

### "مش قادر أكتب نقطة في أول اسم الملف"
اكتب الاسم في **Notepad** → Copy → الصقه في خانة الاسم على GitHub.

### "الـ Actions بتقول The workflow is not triggered"
ده طبيعي لو لسه مفعّلهاش → [الخطوة 3](#الخطوة-3-فعّل-الـ-actions)

### "رفعت الملفات بس طلعت جوه مجلد اسمه main"
`main` ده اسم الـ branch مش مجلد. بص على القائمة — لو شايف ملفاتك تحتها، تمام.

### "عايز أرجع لنسخة قبل ما باظت"
تاب **Code** → على اليمين تحت فيه **Commits** (مثلاً `12 commits`) → اضغطها
→ هتشوف كل التعديلات → اضغط على أي واحد → **Restore** أو انسخ منه.

### "الزرار Run workflow مش موجود"
لازم تكون **جوه** الـ workflow نفسه:
Actions → على الشمال اضغط `generate-daily` → **بعدين** الزرار يظهر فوق على اليمين.
